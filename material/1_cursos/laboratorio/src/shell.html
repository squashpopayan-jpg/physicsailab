Este archivo se está mostrando en una vista previa (de WhatsApp, del correo, de Drive o del visor del celular) que no ejecuta programas. Por eso no aparecen las guías ni las simulaciones. El archivo está bien: sólo hay que abrirlo con un navegador.

Cómo abrirlo

  1. Celular Android: descargue el archivo, ábralo desde la aplicación Archivos (o Descargas) y elija Abrir con → Chrome. También sirven Firefox o Samsung Internet.
  2. iPhone o iPad: el iPhone no ejecuta las simulaciones desde un archivo descargado. Use el enlace web que le comparta su profesor, o ábralo en un computador.
  3. Computador: descargue el archivo y ábralo con doble clic en Chrome, Edge o Firefox.

Se necesita conexión a internet para ver las fórmulas; las simulaciones funcionan sin ella.
